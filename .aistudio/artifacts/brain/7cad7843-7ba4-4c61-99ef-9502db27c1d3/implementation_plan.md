# دارس (Daris) - المساعد الدراسي الصارم الذكي

تطبيق ويب أكاديمي متكامل يجسد شخصية "المعلم الأكاديمي الصارم والمحفز"، يمنع التشتت قطعياً ولا يجيب إلا في إطار المناهج والتعلم، ويوفر بيئة دراسية متكاملة لحل الأسئلة، تلخيص المحاضرات المسجلة والمباشرة، تحويل ملفات الـ PDF لحصص صوتية مجزأة عالية الجودة، توليد بطاقات إنفوجرافيك بصرية للملخصات، وجدول دراسي تفاعلي مع تنبيهات صوتية.

---

## قرارات المراجعة والاختيارات الحاسمة

> [!IMPORTANT]
> بناءً على إجابات الأسئلة التوضيحية، تم اعتماد المواصفات التالية في التصميم والتنفيذ:

- **شخصية المعلم**: أستاذ أكاديمي جاد، منهجي، حازم في طرد أي سؤال غير دراسي، محفز بأسلوب صارم يركز على الدرجات والتحصيل والامتحانات.
- **الحصص الصوتية المستخرجة من الـ PDF**: حلقات دراسية متكاملة ومقسمة لمحاور تفصيلية قابلة للاستماع الفوري وللتحميل الصوتي (WAV) لكل محور أو للدرس كاملاً.
- **الملخصات الصورية المطلوبة**: بطاقات إنفوجرافيك بصرية غنية وخرائط مفاهيمية عالية الدقة والوضوح قابلة للتحميل كصور جاهزة للمراجعة السريعة.
- **تصدير المحتوى**: إمكانية تصدير أي ملخص أو حل مسائل كملف PDF منسق وجاهز للطباعة.

## 1. نظرة عامة والمفهوم الجوهري (Overview & Core Concept)

- **الهدف والوظيفة**: منصة دراسية شاملة للطالب تعزز الانضباط والتركيز المطلق. التطبيق لا يسمح بأي أحاديث جانبية أو تشتيت ("صارم لا يجيب إلا عن الدراسة"). يقوم بحل وشرح المسائل بدقة متناهية من المصادر المرفقة أو الذكاء الاصطناعي، ويدعم الصور (كأوراق الأسئلة والمسائل المكتوبة) وملفات الـ PDF.
- **الفئة المستهدفة**: طلاب المدارس والجامعات، طلاب الشهادات الثانوية والتحضيرية للامتحانات، والباحثون الذين يحتاجون إلى أداة تلخيص وتنظيم دراسي حازمة.
- **القيمة المضافة**:
  1. **حائط الصرامة الأكاديمية (Strict Academic Guardrail)**: خوارزمية ذكية ترفض أي استفسار ترفيهي أو غير دراسي وتعيد توجيه الطالب لمادته.
  2. **مركز الوسائط المتعددة (Multimodal Study Center)**: قراءة الصور، حل المسائل المصورة خطوة بخطوة، واستيعاب ملفات الـ PDF.
  3. **استوديو المحاضرات (Lecture Studio)**: تسجيل المحاضرات مباشرة عبر المايكروفون أو رفع ملفات صوتية لتحويلها لملخص شامل ونقاط امتحانية.
  4. **محول الـ PDF لحصص صوتية (PDF-to-Audio Lecture)**: استخراج دروس محددة من الـ PDF وتحويلها إلى حصة صوتية منهجية مع مشغل صوتي تفاعلي وتنزيل للمقاطع.
  5. **مولد بطاقات الإنفوجرافيك الصورية (Visual Infographic Summaries)**: تصميم بطاقات بصرية وخرائط مفاهيمية للدروس يمكن حفظها ومشاركتها كصور عالية الدقة.
  6. **الجدول الدراسي ومنبهات المذاكرة (Study Planner & Timetable)**: جدول منظم للمواد مع جلسات تركيز (Pomodoro/Focus Timers) وتنبيهات صوتية فورية لإبقاء الطالب في قمة التزامه.

## 2. تجربة المستخدم والتصميم البصري (User Experience & Visual Design)

### المسار التدفقي الرئيسي للمستخدم (Key User Flows)

1. **الواجهة الرئيسية (Strict Workspace)**:
   - رأس صفحة أكاديمي نظيف مع خيارات الانتقال السلسة: [الدروس والأسئلة | تسجيل وتلخيص المحاضرات | الحصص الصوتية من PDF | الجدول والتنبيهات].
   - شريط مؤشر التركيز الأكاديمي والجدول الزمني لليوم.
2. **غرفة المذاكرة وحل الأسئلة (Strict Academic Tutor)**:
   - محادثة تفاعلية صارمة وجادة مع الأستاذ.
   - رفع سريع للصور (مسألة رياضية، صفحة كتاب، مخطط) أو ملفات PDF.
   - عند طلب حل سؤال: يقدم إجابة نموذجية مع الخطوات التفصيلية ومصدر المعلومة وقوانين الحل.
   - زر سريع ومخصص: *"أريد بطاقة ملخص صوري للدرس"* ليقوم المعلم مباشرة بإنشاء لوحة الإنفوجرافيك البصرية القابلة للتحميل كصورة، وزر *"تحميل كملف PDF"*.
3. **استوديو تسجيل وتلخيص الحصص (Live Class Recorder & Audio Summarizer)**:
   - مسجل مايكروفون مباشر مع موجات صوتية حية (Audio Visualizer) ومؤقت تسجيل.
   - إمكانية سحب وإفلات ملف صوتي مسجل مسبقاً (MP3, WAV, M4A, WebM).
   - التلخيص التلقائي: استخراج الأفكار الجوهرية، المصطلحات، أسئلة الامتحانات المتوقعة، وبطاقة مراجعة سريعة.
4. **حصة الـ PDF الصوتية (PDF Audio Classroom)**:
   - رفع ملف PDF وتحديد الفصل أو الموضوع المستهدف.
   - معالجة وتوليد "حلقة درس صوتية" احترافية مقسمة لمحاور (مقدمة المفهوم، الشرح والتحليل، أمثلة وتطبيقات، خلاصة امتحانية).
   - مشغل صوتي مدمج يدعم التحكم بالسرعة (1x, 1.25x, 1.5x)، والتنقل بين المحاور، وزر تنزيل الصوت بصيغة WAV.
5. **منظم الجدول والتنبيهات (Study Schedule & Timer Alerts)**:
   - جدول أسبوعي ويومي للمواد وفترات المذاكرة.
   - عداد تنازلي للمذاكرة المركزة مع منبه صوتي حقيقي (Web Audio API Chime/Bell) عند بدء ونهاية الجلسات والاستراحات.

### الهوية البصرية والنمط التصميمي

- **النمط الجمالي (Aesthetic Direction)**: منصة أكاديمية فاخرة ومهيبة مستوحاة من رصانة الجامعات العريقة مع حداثة التكنولوجيا التعليمية.
- **دعم كامل للغة العربية (RTL First)**: اتجاه من اليمين لليسار، خطوط عربية واضحة ورصينة (مثل Tajawal أو Cairo عبر Google Fonts مع نظام بديل أنيق)، وأرقام مفهرسة بدقة.
- **لوحة الألوان بنسبة 60-30-10**:
  - **60% الخلفية المحايدة**: ألوان أكاديمية مريحة للعين (كحلي ليلي عميق `#0B1120` و `#0F172A` في الوضع الداكن مع كروت `#1E293B`، أو أبيض عاجي عالي الوضوح `#F8FAFC` مع حدود `#E2E8F0`).
  - **30% الهياكل والأسطح**: بطاقات مصقولة بحدود دقيقة (Hairline borders)، تباين عالي للنصوص لقراءة مريحة أثناء ساعات المذاكرة الطويلة.
  - **10% اللمسات المحفزة**: الأزرق الأكاديمي المرموق (`#2563EB`) مع لمسات كهرمانية ذهبية دافئة (`#D97706` / `#F59E0B`) للتأكيدات والمواعيد والأزرار الفعالة.
- **انضباط التصميم (Zero-Pill & Anti-Slop Discipline)**:
  - لا توجد فقاعات ألوان عشوائية أو شارات متراكمة بلا هدف.
  - البيانات الوصفية (التواريخ، عدد الدقائق، حجم الملفات) معروضة كنصوص نظيفة مفصولة بنقاط خافتة (`·`).
  - أزرار صريحة وواضحة بدون تسميات مبهمة.

## 3. القرارات التقنية والخيارات المعمارية (Key Product Decisions)

1. **نموذج الذكاء الاصطناعي وخادم Express**:
   - استخدام `server.ts` كامل مع Express ومكتبة `@google/genai` الرسمية.
   - استخدام النموذج الأساسي الأحدث `gemini-3.8-flash` لمعالجة النصوص والصور واستيعاب الـ PDF والاستجابة الصارمة.
   - استخدام `gemini-3.5-transcribe` لتفريغ الملفات الصوتية والتسجيلات المباشرة بدقة استثنائية.
   - استخدام `gemini-3.8-flash-lite-tts` لتوليد الصوت الأكاديمي الصافي بصيغة WAV للحصص الصوتية المستخرجة من الـ PDF مع خيار التنزيل المباشر كملف صوتي.
2. **حائط الصرامة وضبط المحتوى (Strict Academic Guardrail System)**:
   - تعليمات نظام (System Instructions) صارمة تمنع الخروج عن المواضيع الدراسية والمناهج وتلزم المعلم بالرد بجدية وتوجيه الطالب لدراسته عند محاولة فتح مواضيع خارج المنهج.
3. **توليد الملخصات الصورية (Visual Infographic Summary Generation)**:
   - يدمج التطبيق مولد بطاقات إنفوجرافيك ثنائي القوة:
     1. لوحة تفاعلية بصرية فائقة الأناقة ذات تخطيط شبكي منظم (المفاهيم، القوانين، الملاحظات الحرجة) مبنية باستخدام Canvas عالي الدقة وتقنية تنزيل فورية بصيغة PNG/JPG مع خطوط عربية منسقة.
     2. دعم إضافي لتوليد صور توضيحية ورسوم بيانية عبر واجهة خلفية للمفاهيم التي تتطلب رسماً دقيقاً.
4. **تصدير الـ PDF**:
   - إمكانية طباعة وتصدير الملخصات بصيغة PDF أنيقة ومنسقة جاهزة للطباعة والمراجعة الورقية بضغطة زر واحدة.
5. **التخزين المحلي للجدول والمحاضرات (Persistence via LocalStorage)**:
   - حفظ جدول المذاكرة، جلسات المؤقت، الملاحظات، وسجل الأسئلة محلياً في المتصفح لضمان عدم ضياع بيانات الطالب حتى لو أغلق المتصفح.

## 4. البنية التقنية ومخطط النظام (Technical Architecture)

```
┌────────────────────────────────────────────────────────────────────────┐
│                        واجهة العميل (React 19 + Vite)                   │
├────────────────────────────────────────────────────────────────────────┤
│  ┌───────────────────────┐  ┌────────────────────────────────────────┐ │
│  │   Strict Tutor Chat   │  │   Lecture Studio (Mic + Audio Files)   │ │
│  │ (Q&A, Images, PDFs)   │  │   (Visualizer, Transcribe & Summary)   │ │
│  └───────────┬───────────┘  └───────────────────┬────────────────────┘ │
│              │                                  │                      │
│  ┌───────────┴───────────┐  ┌───────────────────┴────────────────────┐ │
│  │  PDF to Audio Lesson  │  │   Study Timetable & Focus Reminders    │ │
│  │ (Chapter Scrubber/WAV)│  │   (Audio Chimes, Pomodoro, Schedule)   │ │
│  └───────────┬───────────┘  └───────────────────┬────────────────────┘ │
│              │                                  │                      │
│  ┌───────────┴──────────────────────────────────┴────────────────────┐ │
│  │  Infographic Canvas Card Exporter & PDF Document Generator Sheet  │ │
│  └──────────────────────────────────┬────────────────────────────────┘ │
└─────────────────────────────────────┼──────────────────────────────────┘
                                      │ HTTP /api Proxy Requests
┌─────────────────────────────────────▼──────────────────────────────────┐
│                   خادم Express الداعم (server.ts)                      │
├────────────────────────────────────────────────────────────────────────┤
│  /api/tutor/ask          -> Strict Academic Prompt + Gemini 3.8 Flash │
│  /api/lecture/transcribe -> Gemini 3.5 Transcribe (Audio to Text)      │
│  /api/audio-lesson/gen   -> Gemini 3.8 Flash-Lite TTS (Lesson to WAV)  │
│  /api/infographic/draft  -> Structured Data for Visual Canvas Export    │
└────────────────────────────────────────────────────────────────────────┘
```

### خطة ملفات التنفيذ

- `server.ts`: خادم Express متكامل يقدم مسارات API للذكاء الاصطناعي مع تحويل الـ PDF والصور والملفات الصوتية، وتوليد نطق الـ TTS، مع دمج وسيط Vite للمعاينة الحية.
- `src/services/api.ts`: عميل دوال الاتصال بالخادم الخلفي للمحادثة، التسجيل، والصوتيات.
- `src/components/StrictTutorView.tsx`: واجهة الأستاذ الصارم مع رفع الصور والـ PDF وحل المسائل خطوة بخطوة.
- `src/components/LectureStudioView.tsx`: استوديو التسجيل المباشر واستقبال الملفات الصوتية مع محلل الموجات وتلخيص المحاضرة.
- `src/components/PdfAudioLessonView.tsx`: استخراج الحصص من الـ PDF، تقسيمها لمحاور صوتية، ومشغل صوتيات متقدم مع تحميل ملفات الصوت.
- `src/components/InfographicSummaryModal.tsx`: مولد بطاقات الإنفوجرافيك البصرية على Canvas عالي الدقة مع زر التنزيل الفوري كصورة.
- `src/components/StudyTimetableView.tsx`: جدول المذاكرة اليومي والأسبوعي مع مؤقت المذاكرة ومنبهات صوتية واقعية.
- `src/components/PdfExportModal.tsx`: مولد أوراق المراجعة الجاهزة للطباعة والتصدير كـ PDF.
- `src/components/TopNav.tsx`: شريط تنقل قياسي من صف واحد وثلاث مناطق وفق اشتراطات التصميم، متجاوب تماماً.
- `src/App.tsx`: المنظم الرئيسي لتبديل النوافذ، حفظ الحالة محلياً، والتنبيهات المجدولة.

## الخطوات القادمة بعد الاعتماد
فور موافقتك على الخطة:
1. إعداد خادم `server.ts` وتحديث مسارات تشغيل السيرفر الموحد.
2. بناء منطق المعلم الصارم ومحركات الذكاء الاصطناعي للـ Multimodal والـ TTS والتفريغ الصوتي.
3. تشييد واجهات المستخدم بالكامل بأسلوب أكاديمي عربي راقٍ مع تفاعل صوتي وبصري كامل وفحص البناء بالـ compiler.
